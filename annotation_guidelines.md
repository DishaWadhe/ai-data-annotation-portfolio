# Sentiment Annotation Guidelines

## Purpose

The purpose of this project is to classify text according to its sentiment.

## Labels

### Positive

Use the Positive label when the text expresses satisfaction, happiness, approval, praise, or a favorable opinion.

**Example:**
"I love this product."

**Label:** Positive

### Negative

Use the Negative label when the text expresses dissatisfaction, disappointment, criticism, anger, or an unfavorable opinion.

**Example:**
"The service was terrible."

**Label:** Negative

### Neutral

Use the Neutral label when the text provides factual information without expressing a clear positive or negative opinion.

**Example:**
"The package arrived today."

**Label:** Neutral

## Annotation Rules

1. Read the complete text before assigning a label.
2. Consider the overall meaning and context.
3. Do not assign a label based only on individual words.
4. Use Neutral when there is no clear sentiment.
5. Apply the same rules consistently to all examples.
6. Review ambiguous examples carefully before assigning a label.

## Quality Standards

Annotations should be accurate, consistent, and based on the defined guidelines.

When uncertain, review the annotation rules and consider the complete context before making a decision.
