# Annotation Guidelines

This folder contains practice guidelines and evaluation criteria used for AI data annotation and AI response evaluation.

## Documents

- Sentiment Annotation Guidelines
- AI Response Evaluation Rubric

## Quality Principles

- Follow the defined annotation rules.
- Read the complete context before labeling.
- Maintain consistency across annotations.
- Evaluate AI responses objectively.
- Clearly explain the reason for evaluation decisions.

All guidelines are self-created practice materials.
